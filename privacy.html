Privacy policy

For the application "Claude on my Mac". Last updated 27 September 2026.

Who this covers

This application has a single user, who is also its owner. It runs on one personal computer and is not offered to anyone else. There are no accounts, no sign-ups and no customers.

What it accesses

When the owner signs in, the application asks Google for permission to use:

  • Google Drive. To list, search, read and download the owner's own files, and to upload new files to the owner's own Drive.
  • Google Calendar. To list the owner's own calendars and read events on them.
  • Email address. To confirm which account signed in, so the application works on the right account.

Where the data goes

Nowhere except between the owner's computer and Google. The application has no server, no database and no hosting of any kind. File contents are read into memory on the computer to do the task asked of it, and files the owner chooses to upload are sent to the owner's own Google Drive. Nothing is sent to any other destination.

What is stored, and where

  • The Google sign-in credentials are stored in the macOS keychain on the owner's own computer. They are not written to any file and are not copied anywhere.
  • Files downloaded at the owner's request are saved on the owner's own computer, in the place the owner chose.
  • No log of Google data is kept.

What is never done

  • Google user data is not sold.
  • Google user data is not shared or transferred to any third party.
  • Google user data is not used for advertising, analytics, profiling, or to train any machine learning or artificial intelligence model.
  • No other person's Google account is used with this application.

Limited Use

This application's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

Because nothing is stored off the computer, there is nothing held elsewhere to delete. The owner can withdraw the application's access at any time at myaccount.google.com/permissions, which immediately stops all access. Removing the saved credentials from the macOS keychain has the same effect locally.

Children

The application is not directed at children and has no users other than its owner.

Changes

If what the application does changes, this page will be updated and the date at the top will change with it.

Contact
